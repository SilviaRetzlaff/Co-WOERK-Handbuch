## Arbeitsregeln
- Wir arbeiten nicht direkt in `main`.
- Für eine konkrete Aufgabe wird ein eigener Branch angelegt.
- Branches und Pull Requests erhalten verständliche Namen.
- Änderungen werden in überschaubaren Einheiten eingereicht.
- Mindestens eine andere Person prüft den Pull Request.
- Rückfragen und Änderungsvorschläge werden direkt im Pull Request dokumentiert.
- Offene Diskussionen werden vor dem Merge geklärt.
- Nach dem Merge wird der freigegebene Stand lokal aktualisiert.
